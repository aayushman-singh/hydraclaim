# Domain documents

This repository uses one domain context.

## Required reading

Before architecture work, read these files when they exist:

1. Read `CONTEXT.md` at the repository root.
2. Read applicable architecture decision records in `docs/adr/`.

Use the terms from `CONTEXT.md`. Do not replace these terms with synonyms.

If a proposal conflicts with an architecture decision record, identify the record and explain why the decision must change.

Create `CONTEXT.md` only when the project must define or change a domain term. Create an architecture decision record only when the project accepts a long-term design decision.
