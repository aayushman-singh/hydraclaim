# Triage labels

Use this mapping for the five triage roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must supply more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the full issue without more information. |
| `ready-for-human` | `ready-for-human` | A person must implement the issue. |
| `wontfix` | `wontfix` | The project will not implement the issue. |
